Описание

Алгоритм построения маршрута между двумя точками на свободной прямоугольной сетке.

Вместо использования алгоритмов обхода графа, таких как BFS, метод вычисляет точку поворота непосредственно по координатам начальной и конечной точек.

Алгоритм

Даны две точки:

* A = (x₁, y₁) — начальная точка
* B = (x₂, y₂) — конечная точка

Точка поворота вычисляется по формуле:

P = (x₁, y₂)

Маршрут строится следующим образом:

A → P → B

Таким образом, робот достигает конечной точки, совершая не более одного поворота.

Пример

A = (0, 0)
B = (2, 1)

Точка поворота:

P = (0, 1)

Маршрут:

A → P → B

Сложность

Параметр	Значение
Временная сложность	O(1)
Пространственная сложность	O(1)
Максимальное количество поворотов	1
Построение графа	Не требуется

Ограничения

Алгоритм предназначен для свободных прямоугольных сеток без препятствий, при условии возможности движения по горизонтали и вертикали в обоих направлениях.

Идея

Метод разработан самостоятельно путём анализа геометрических свойств задачи. Основная идея — определить, можно ли построить маршрут напрямую, без использования алгоритмов поиска.
